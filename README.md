## 🚀 Features

- Responsive design (mobile friendly)
- User authentication & registration
- Product categories & detailed item views
- Shopping cart & checkout flow
- Order history & profile dashboard
- Modern UI with smooth navigation

---

## 🛠️ Tech Stack

- **Frontend:** HTML / CSS
- **Backend:** FastAPI
- **Deployment:** [Render](https://lumina-ecommerce-h6e3.onrender.com)
- **Styling:** TailwindCSS
